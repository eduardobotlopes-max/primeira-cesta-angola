# Sua Primeira Cesta Vendida — Angola

Quiz estático com 17 etapas, estrutura HTML e estilos extraídos da referência e textos adaptados para Angola. Preço da oferta: **4.990 Kz**.

## Executar

Abra `index.html` com um servidor estático, por exemplo `python -m http.server 8765`.

## Publicar na Vercel

Importe este repositório. Preset: **Other**. Sem comando de build; pasta de saída: raiz (`.`).

## Checkout

Defina `CHECKOUT_URL` no final de `index.html` com o checkout próprio de 4.990 Kz. Enquanto estiver vazio, o botão abre um aviso de inscrições em breve. O checkout brasileiro da referência foi removido. Os parâmetros UTM são encaminhados quando o checkout estiver configurado.

## Ficheiros

As sete imagens estão em WebP, juntamente com a fonte e as folhas de estilo originais. Não dependem dos servidores de imagens da referência. Os relatos brasileiros foram conservados como imagens originais e identificados como relatos do Brasil.
